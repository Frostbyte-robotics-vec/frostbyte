## Ziel
Der Workflow .github/workflows/board-done.yml setzt beim Merge jedes ticket/*-PRs den Status auf done.
Für ein Ticket mit Status needs_hw überspringt das den Hardware-Test (gefunden im Review von PR #8, F-04).

## Fertig, wenn …
- Merge eines PRs, dessen Ticket auf needs_hw steht, lässt den Status needs_hw (oder setzt einen eindeutigen
  Zwischenstatus, der in tools/board.py validate bekannt ist); review → done bleibt wie bisher
- Verhalten ist in tools/board.py als Funktion getestet (nicht nur im YAML)
- Laptop-Tests grün, beide Roboter bauen, `python tools/board.py validate` grün

## Kontext
Bis S-05 erledigt ist: PRs von needs_hw-Tickets erst nach dem Hardware-Test mergen. Regeln: CLAUDE.md.
