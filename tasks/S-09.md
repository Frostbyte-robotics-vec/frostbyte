## Ziel
Die CI-Jobs „roboter (stacker/runner)“ sind auf main rot: `apt` liefert auf ubuntu-latest inzwischen gcc-arm 13.2, `common.mk` verlangt `--std=gnu++26` (erst ab GCC 14). Die CI soll dieselbe Toolchain nutzen wie die lokale PROS-Installation (Arm GNU Toolchain 14.3.Rel1) und nicht mehr vom Paketstand des Runners abhängen. Entscheidung als ADR-021.

## Fertig, wenn …
- ci.yml lädt Arm GNU Toolchain 14.3.rel1 (fest, mit Cache) statt `apt install gcc-arm-none-eabi`
- „roboter (stacker)“ und „roboter (runner)“ grün im PR
- ADR-021 beschreibt Wahl, Quelle, Update-Weg
- `python tools/board.py validate` grün

## Kontext
Rot seit PR #29 (Lauf 41406373566); blockiert die Checks von PR #30 (M-01). Regeln: CLAUDE.md.
